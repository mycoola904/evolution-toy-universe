# 11. Roadmap

## 1. Purpose

This roadmap describes the planned evolution of the Evolution Toy Universe project. Development proceeds in small, testable milestones. Each milestone should result in a working simulation, even if only with placeholder behavior.

The roadmap is intended to communicate direction rather than act as a detailed task list.

---

## 2. Guiding Philosophy

Development follows several principles:

- Build the simplest working version first.
- Prefer observable behavior over optimization.
- Add complexity only after simpler models have demonstrated their limits.
- Every milestone should produce something that can be visualized and tested.
- Preserve deterministic behavior whenever practical.

---

## 3. Version 1 — Minimal Living Universe

### Goal

Create a complete closed-loop simulation where evolution can begin.

### Components

- Simulation loop
- Toroidal world
- Environmental energy generation
- Organisms
- Neural network execution
- Energy accounting
- Reproduction
- Mutation
- Death
- Basic UI visualization

### Expected Outcome

Organisms survive, reproduce, compete for resources, and evolve simple behaviors.

This is the project's first major success milestone.

---

## 4. Version 2 — Better Observation

Once evolution exists, improve our ability to understand it.

### Possible Additions

- Genome viewer
- Neural network viewer
- Population graphs
- Species clustering
- Simulation statistics
- Replay support
- Faster simulation speeds
- Save/load experiments

The simulation rules remain mostly unchanged.

---

## 5. Version 3 — Richer Environment

Expand the world itself.

### Possible Additions

- Terrain types
- Resource gradients
- Seasonal changes
- Environmental hazards
- Resource regeneration models
- Multiple energy sources

The environment becomes more varied without changing the fundamental organism model.

---

## 6. Version 4 — Richer Organisms

Increase biological complexity.

### Possible Additions

- Memory neurons
- Additional sensors
- Communication
- Lifespan limits
- Larger genomes
- Developmental genes

Organisms gain new ways to adapt.

---

## 7. Version 5 — Ecosystems

Allow new ecological interactions to emerge.

### Possible Additions

- Predation
- Scavenging
- Waste products
- Food chains
- Cooperative behavior
- Ecological niches

This version explores whether complex ecosystems emerge naturally.

---

## 8. Version 6 — Experiments

Focus shifts from building the simulator to using it as an experimental platform.

### Example Experiments

- Effect of mutation rate
- Resource abundance
- Neural network size
- Population bottlenecks
- Catastrophic events
- Competition between strategies

The simulator becomes a tool for exploring emergent behavior.

---

## 9. Future Ideas

The following ideas are intentionally outside the scope of Version 1.

Examples include:

- Sexual reproduction
- Multiple species
- Vision with obstacles
- Learning during an organism's lifetime
- Genetics inspired by real biology
- Distributed simulation
- GPU acceleration
- Three-dimensional visualization
- Networked experiments

These features may be explored as the project evolves.

---

## 10. Completion Criteria for Version 1

Version 1 is considered complete when:

- The simulation runs continuously.
- Organisms consume energy.
- Organisms move according to neural network outputs.
- Organisms reproduce.
- Mutation occurs.
- Organisms die.
- Population dynamics can be observed.
- Simulations are repeatable when using the same random seed.

At this point, the project has achieved its primary objective: a functioning artificial universe in which evolution can emerge from simple rules.

---

## 11. Looking Beyond

The roadmap intentionally emphasizes incremental growth rather than implementing every possible feature from the beginning. By first establishing a minimal but complete simulation, later versions can be guided by observation rather than speculation.

The long-term goal is not simply to build a complex simulation, but to create a system in which increasingly interesting behaviors emerge naturally from a small set of understandable rules.
